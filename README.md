#SimpleClearLag
A simple yet powerful clearlag for fabric 26.1.2

### FEATURES
- /clearlag command with **proper permition checks**
- automatic timers and **5 second warnings**
- **XP, arrow (stuck in block), trident (stuck in block), and area effect cloud removal**
- **lightweight** footprint with zero background performance impact on the server
- **instant entity deletion** without requiring a server reboot to take effect
- hardcoded defaults **optimized for vanilla gameplay** to keep installation plug and play
- And **MORE** comming soon!
